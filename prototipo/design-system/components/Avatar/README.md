# Avatar

Foto ou iniciais de uma pessoa. As iniciais usam uma das oito cores de categoria (fundo `cat-*-soft`, letra `cat-*-ink`), escolhida pelo nome: a mesma pessoa tem sempre a mesma cor.

**O consumidor fornece:** `name` (sempre, vira texto para leitor de tela), `src`, `size`, `status` (online, ausente).

- Foto de aluno só aparece para quem tem permissão e com consentimento da família (LGPD e ECA Digital).
