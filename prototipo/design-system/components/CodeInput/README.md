# CodeInput

Código de verificação para entrar sem senha. Avança sozinho, volta com Backspace e aceita colar o código inteiro.

**O consumidor fornece:** `length` (padrão 6), `onComplete(codigo)`, `error`, `hint` com o destino mascarado.

- `autocomplete="one-time-code"` permite preencher pelo SMS no celular.
