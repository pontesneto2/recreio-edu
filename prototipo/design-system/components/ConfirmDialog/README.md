# ConfirmDialog

Confirmação para ação que não se desfaz. Diz exatamente o que vai acontecer.

**O consumidor fornece:** `title` em forma de pergunta com o objeto ("Cancelar a matrícula de Davi Lima?"), texto com as consequências, `confirmLabel` repetindo o verbo, `cancelLabel` dizendo o que fica, `tone`, `loading`.

- Não faça: botões "Sim" e "Não".
