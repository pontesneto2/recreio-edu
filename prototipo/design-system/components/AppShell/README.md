# AppShell

Esqueleto de toda tela logada: navegação lateral no desktop, barra superior, conteúdo e barra inferior no celular.

**O consumidor fornece:** `sidenav`, `topbar`, `tabbar`, conteúdo e `aside` opcional (painel secundário, escondido no modo foco).

- Abaixo de 860 px a lateral some e a TabBar aparece.
- Conteúdo limitado a `content-max` (1200 px).
