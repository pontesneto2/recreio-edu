# Sheet

Gaveta lateral no desktop e folha que sobe de baixo no celular.

**Quando usar:** filtros, detalhes de um item sem sair da lista, formulários médios no celular.

**O consumidor fornece:** `open`, `onClose`, `title`, conteúdo, `footer`, `width` no desktop.

- No celular tem alça visual e ocupa até 88% da altura.
