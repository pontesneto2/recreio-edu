# IconButton

Botão só com ícone para ações repetidas e conhecidas (fechar, mais ações, notificações).

**O consumidor fornece:** `icon`, `label` obrigatório (vira o nome acessível e a dica ao passar o mouse), `badge` (número ou `true` para ponto), `variant` (ghost, secondary, primary).

- Área de toque mínima de 44 px em telas de toque.
- Não faça: usar para ações raras ou ambíguas; nesses casos, botão com texto.
