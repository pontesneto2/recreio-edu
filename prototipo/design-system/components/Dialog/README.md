# Dialog

Janela modal para uma decisão ou formulário curto que precisa de atenção total.

**O consumidor fornece:** `open`, `onClose`, `title`, `description`, conteúdo, `footer` com as ações (primária à direita), `size` (sm, md, lg), `dismissable`.

- Prende o foco, fecha com Esc e clique fora, devolve o foco ao botão que abriu.
- Entra com leve escala e sai mais rápido do que entrou.
- No celular, para formulários longos, prefira Sheet.
