# Alert

Aviso dentro da página. Diz o que aconteceu e o que fazer, com a ação ali mesmo.

**O consumidor fornece:** `tone` (info, success, warning, danger), `title`, texto, `actions`, `onClose` quando pode ser dispensado.

- `danger` é anunciado imediatamente para leitor de tela.
- Não faça: empilhar vários avisos no topo da página; junte em um.
