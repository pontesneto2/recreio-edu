# FileDrop

Envio de documentos com arrastar e soltar e progresso por arquivo.

**O consumidor fornece:** `files` (`name`, `progress` 0 a 100, `size`, `error`), `onFiles`, `onRemove`, `accept`, `hint` com formatos e tamanho.

- Erro de arquivo diz o que fazer.
- No celular o botão abre câmera ou galeria.
