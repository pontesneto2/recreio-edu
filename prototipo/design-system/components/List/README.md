# List

Lista vertical de itens com elemento inicial, título, metadado e elemento final. Itens entram em sequência.

**O consumidor fornece:** `List` com `label` e `divided`; cada `ListItem` com `leading`, `title`, `meta`, `trailing`, `onClick` ou `href`, `unread`, `index` (para a entrada em sequência).

- É a versão de celular das tabelas.
