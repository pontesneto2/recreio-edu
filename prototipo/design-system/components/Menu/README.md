# Menu

Lista de ações de um item, aberta por um botão.

**O consumidor fornece:** `items` (`label`, `icon`, `hint`, `tone`, `disabled`, `onClick`; `'-'` para separador), `trigger` opcional, `align`.

- Setas navegam, Esc fecha, clique fora fecha.
- Ação destrutiva por último, separada, em vermelho, e sempre com ConfirmDialog.
