# Card

Superfície base para agrupar conteúdo relacionado: fundo branco, borda fina e sombra leve tingida de marinho (`shadow-1`).

**O consumidor fornece:** `title`, `subtitle`, `actions`, conteúdo, `footer`, `padding` (sm, md, none), `interactive` (o cartão inteiro é clicável: sobe 1 px no hover), `href`.

- Cartão clicável sobe 2 px e ganha borda na cor da escola no hover.
- Não faça: cartão dentro de cartão.
