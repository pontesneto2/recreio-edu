# StatCard

Indicador principal: número que conta até o valor, variação com cor de bom ou ruim e tendência.

**O consumidor fornece:** `label`, `value`, `format`, `delta`, `deltaSuffix` ("%", " p.p."), `deltaLabel`, `goodWhen` ("up" ou "down": inadimplência boa é a que cai), `trend` (série para a linha), `icon`, `href`, `loading`, `color` (categoria: azul, verde, amarelo, laranja, vermelho, roxo, ciano, rosa) e `variant="hero"` (degradê marinho para o número principal da tela, um por tela).

- Número com algarismos tabulares. A contagem respeita movimento reduzido.
