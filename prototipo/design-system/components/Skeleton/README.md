# Skeleton

Forma do conteúdo que está chegando, com brilho que corre por cima. Reduz a sensação de espera e evita que a tela pule.

**O consumidor fornece:** `variant` (text, circle, rect), `lines`, `width`, `height`.

- O brilho desliga com movimento reduzido.
- Envolva o bloco em algo com `aria-busy` ou use LoadingCard, que já anuncia o carregamento.
