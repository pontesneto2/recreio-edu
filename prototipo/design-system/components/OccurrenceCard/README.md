# OccurrenceCard

Ocorrência do aluno: tipo (disciplinar, pedagógica, saúde, elogio, atraso) com cor e ícone, gravidade, relato, providência tomada e ciência do responsável.

**O consumidor fornece:** `kind`, `level`, `student`, `group`, `date`, `author`, o relato como conteúdo, `measures`, `acknowledged`, `ackBy`, `onAcknowledge`, `guardianView` (a família vê o botão Estou ciente).

- Elogio também é ocorrência: o sistema não serve só para registrar problema.
- Saúde só aparece para perfis com permissão de saúde.
