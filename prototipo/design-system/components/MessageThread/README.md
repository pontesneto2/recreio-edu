# MessageThread

Conversa por assunto entre família e escola. Várias mensagens seguidas, anexos, leitura, prazo de resposta visível e indicação de que alguém está escrevendo.

**O consumidor fornece:** `subject`, `participants`, `sla`, `messages` (`from`, `author`, `text`, `file`, `time`, `status`), `me`, `onSend`, `typing`.

- Enter envia, Shift + Enter quebra linha.
- Os dois responsáveis veem a mesma conversa quando a escola permite.
