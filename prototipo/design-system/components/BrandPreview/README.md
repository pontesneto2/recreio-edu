# BrandPreview

Prévia do tema da escola no painel de administração: mini app com a cor escolhida, as cores geradas, as medições de contraste e o aviso quando o sistema ajustou a cor.

**O consumidor fornece:** `name`, `seed`, `logo`, `mode`.

- O admin vê antes de publicar. Nenhuma cor que reprova contraste chega às famílias.
