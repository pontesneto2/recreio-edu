# Checkbox

Caixa de seleção independente. O check se desenha ao marcar.

**O consumidor fornece:** `label`, `description`, `checked` ou `defaultChecked`, `indeterminate` (seleção parcial em tabelas), `onChange`.

- Área de clique inclui o texto.
- Não faça: usar para escolhas exclusivas (use RadioGroup) nem para ligar algo com efeito imediato (use Switch).
