# CopyButton

Copia um texto e confirma com um check que se desenha, voltando ao estado inicial em 2 segundos.

**Quando usar:** Pix copia e cola, matrícula, protocolo, código de convite.

**O consumidor fornece:** `text`, `label`, `copiedLabel` e `onCopied` (para registrar o evento).

- A confirmação é anunciada para leitor de tela.
