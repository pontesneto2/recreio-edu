# Badge

Contador ou ponto de aviso.

**Quando usar:** número de itens novos, ponto de "não lido", indicador ao vivo (`pulse`).

**O consumidor fornece:** conteúdo, `tone` (brand, neutral, danger, accent), `dot`, `pulse`, `label` quando for só ponto.

- Status com palavra (pago, vencido) é StatusPill.
