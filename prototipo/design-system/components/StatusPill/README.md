# StatusPill

Status com ícone e palavra, sempre os dois.

**Tons:** `success` (concluído, pago, presente; azul de propósito, para quem tem daltonismo), `warning` (atenção, a vencer), `danger` (erro, vencido, falta), `info` (em andamento, agendado), `neutral` (rascunho, arquivado), `brand` (marca da escola, uso livre).

**O consumidor fornece:** texto curto, `tone`, `icon` para trocar o padrão, `size`.
