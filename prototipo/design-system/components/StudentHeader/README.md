# StudentHeader

Cabeçalho da ficha 360 do aluno: identidade, turma, matrícula, responsáveis, situação e atalhos.

**O consumidor fornece:** `name`, `photo`, `group`, `enrollment`, `guardians`, `tags` (`label`, `tone`, `icon`), `actions`.

- Etiquetas de saúde e inclusão só aparecem para perfis com permissão.
